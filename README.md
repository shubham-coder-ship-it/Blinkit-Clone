Blinkit Landing Page Clone
Project Overview
This project is a responsive frontend clone of the Blinkit homepage, created using HTML5 and CSS3. It recreates the main visual sections of the reference design, including the navigation bar, promotional banner, promotional cards, product categories, and footer.
Features
1. Header / Navigation Bar
- Blinkit logo
- Delivery location and estimated delivery time
- Product search bar
- Login link
- My Cart button
2. Main Promotional Banner
- Large promotional banner with a grocery image
- Heading: "Stock up on daily essentials"
- Supporting description
- Shop Now button
3. Promotional Cards
Three promotional cards are included:
- Pharmacy at your doorstep
- Pet care supplies
- Baby care essentials
Each card includes a heading, short description, image, and Order Now button.
4. Product Categories
- Product category images and names
- Responsive grid layout
- Categories based on the assignment reference, including fruits and vegetables, dairy, snacks, beverages, bakery products, and household essentials
5. Footer
- Useful links
- Product categories
- Help and support links
- Social media links
- Copyright information
Technologies Used
- HTML5 – Page structure and content
- CSS3 – Styling, Flexbox, CSS Grid, and responsive media queries
- Google Fonts (Inter) – Typography
- Unsplash – External images used in the page
Project Structure
blinkit_clone/
├── index.html
├── style.css
└── README.md
How to Run
1. Download or clone the project.
2. Keep index.html, style.css, and README.md in the same folder.
3. Open index.html in a web browser such as Google Chrome.
4. Make sure you have an internet connection to load the external fonts and images.
No installation or build tools are required.
Responsive Design
CSS media queries adjust the layout for desktop, tablet, and mobile screens. The header, promotional cards, category grid, and footer adapt to smaller screen sizes.
Limitations
- This is a frontend design assignment; it does not include backend integration.
- Search, login, cart, location selection, and promotional buttons are visual elements and are not connected to working application features.
- Product and promotional images are loaded from external URLs, so they require an internet connection.
Assignment Objective
The objective is to recreate the appearance of the Blinkit landing page using HTML5 and CSS3, with attention to layout, colors, typography, images, spacing, and responsive behavior.
